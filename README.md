# FemtoRV Generic FPGA Simulation


This repository provides a framework for simulating a hardware design based on the **FemtoRV** processor targeted for generic FPGAs. Using **Verilator**, the design translates Verilog HDL into C++ code to run high-performance cycle-accurate simulations that model real-world hardware as closely as possible.

---

## Dependencies & Prerequisites

To build and run the hardware simulation, you will need a set of open-source EDA tools (specifically `verilator`, `make`, and C++ compilers).

### Recommended Toolchain: oss-cad-suite
The easiest way to set up the complete toolchain environment is by using the **[oss-cad-suite](https://github.com/YosysHQ/oss-cad-suite-build)**.

1. Download the latest release for your OS from the [oss-cad-suite releases page](https://github.com/YosysHQ/oss-cad-suite-build/releases).
2. Extract the archive to your preferred directory.
3. Activate the environment in your terminal session before building:

```bash
# On Linux/macOS
source /path/to/oss-cad-suite/environment

# On Windows (PowerShell)
\path\to\oss-cad-suite\environment.ps1
```

## How to Run the Simulation
Follow these steps to compile the firmware and launch the main simulation:

### Step 0: Set up the firmware files.

On the root run:
```bash
make BENCH.firmware_config
```

### Step 1: Compile the Firmware

Before starting the simulation, you must generate a `.hex` firmware binary file that the processor will load into memory.

1. Navigate to the firmware examples directory:
   ```bash
   cd firmware/examples
   ```

2. Build your target example to output a `.hex` file (replace `nameOfExample` with the target name):
   ```bash
   make nameOfExample.hex
   ```
   *The generated `.hex` file will automatically be placed under the `firmware/` directory.*

### Step 2: Build and Launch the Simulation
> [!WARNING]
> Most examples in the `examples` folder output to the terminal rather than the screen. If you want to test the graphical or visual output, we recommend using `riscv_logo.c` as an example.

> [!NOTE]
> This project is a work in progress. Future updates plan to streamline the examples down to only what the console requires.

Return to the root directory of the repository and execute `make` to compile the C++ simulation model generated by Verilator and run the executable:

```bash
# Return to repository root
cd ../..

# Build and run everything
make
```
